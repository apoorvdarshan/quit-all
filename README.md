# Quit All — Website

Official website for the [Quit All](https://github.com/apoorvdarshan/quit-all) iOS app.

Hosts the app's landing page, Privacy Policy, Terms of Service, and Support/FAQ.

## Pages

- **Home** — App overview, features, and download link
- **Privacy Policy** — How we handle data (spoiler: everything stays on your device)
- **Terms of Service** — Subscription terms, medical disclaimer, usage rules
- **Support** — FAQ and contact info

## Stack

Single static HTML page. No frameworks, no build tools, no dependencies. Just HTML + CSS + vanilla JS.

## Run Locally

```
python3 -m http.server 3000
```

Open http://localhost:3000

## Deploy

Host anywhere that serves static files — GitHub Pages, Vercel, Netlify, etc.
